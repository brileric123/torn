THORNED WEBSITE — UPDATED PROJECT

Files: index.html, shop.html, outerwear.html, upper.html, bottom.html, accessories.html, about.html, contact.html, cart.html, checkout.html, style.css, script.js.

HOW TO RUN
1. Keep all files and product image assets in the same folder.
2. Open the folder in Visual Studio Code.
3. Run index.html using Live Server.

Shopping features added: product descriptions and stock labels, quick-view product details, clothing size selection, add-to-cart, cart review and quantity controls, Philippine peso totals, and checkout details form.

IMPORTANT: This is a front-end demo. Cart data is saved in the browser's localStorage. Checkout only creates a demo confirmation; it does not process payment, submit orders to a business, or reserve actual stock. Stock counts are demo placeholders.
